Torn Company Assistant

Purpose:

Torn Company Assistant is an automated management dashboard for players and company directors of the Torn text-based RPG. Using a user-provided Limited-Access Torn API Key and an optional Torn Stats API Key, it securely retrieves live company and employee data, effectiveness statistics, daily logs, and financial records. The application turns that data into company dashboards, position-efficiency projections, staffing recommendations, stock and profit reports, and historical trends. It also generates, updates, and formats custom management spreadsheets in the user's Google Drive, helping directors manage their company efficiently while keeping their personal data private and under their control.

How Google APIs are Accessed:

Torn Company Assistant accesses the Google Sheets API using only the Google Drive drive.file scope. When you authenticate through Google OAuth, the application can create, read, edit, and format Google Sheets that it creates or that you explicitly select with Google Picker. It does not request the broad Google Sheets, Google Docs, or Google Drive scopes and cannot browse your unrelated files, photos, or documents. Real-time data retrieved from the Torn API is written directly to the designated Sheet files to compile your automated company dashboard.

Google API Disclosure: Torn Company Assistant's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy , including its Limited Use requirements. User data is never sold, shared with third parties, or used for serving advertisements.
